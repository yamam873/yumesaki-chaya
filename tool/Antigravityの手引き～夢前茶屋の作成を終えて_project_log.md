# 夢前茶屋 サイト制作・作業記録（振り返り用）

このドキュメントは、「夢前茶屋」のWebサイトをどのような手順・手法で作成したかをまとめた作業記録です。今後の別プロジェクトで「あれ、あの時どうやって進めたんだっけ？」と迷った時に、いつでも振り返れるように整理しています。

---

## 🏗️ 全体の流れ（大きなステップ）

今回のサイト制作は、主に以下のステップで進行しました。

1. **ベースの準備**: テーマの基礎となるファイル群の作成
2. **パーツの共通化**: ヘッダー・フッターの分割
3. **トップページの実装**: `front-page.php` の作成
4. **動的コンテンツの実装**: お品書き（カスタム投稿タイプ）の一覧ページ作成
5. **静的ページの実装**: アクセス・お問い合わせページの作成
6. **最終調整・リファクタリング**: `style.css`の整理、レスポンシブ対応

---

## 📝 各ステップの詳細手順と手法

### 1. ベースの準備（テーマの初期設定）
まずは、WordPressがテーマとして認識するために必要な最小限のファイルを用意し、設定を行いました。

- **作成・編集した主なファイル**: `style.css`, `index.php`, `functions.php`
- **やったこと**:
  - `style.css`の先頭にテーマ情報を記述（Theme Nameなど）。
  - `functions.php` で `wp_enqueue_style()` や `wp_enqueue_script()` を使い、CSSファイルやJavaScriptファイルを正しく読み込ませる設定を追加。（※HTMLに直書きせず、関数を使うのがWordPressの正しい作法です）
  - テーマサポート（アイキャッチ画像の有効化など）を `functions.php` に追記。

### 2. パーツの共通化（ヘッダー・フッター）
全ページで共通する「ナビゲーションメニュー」や「フッター情報」を分割しました。

- **作成したファイル**: `header.php`, `footer.php`
- **やったこと**:
  - `<!DOCTYPE html>`から`<header>`部分までを `header.php` に切り出し。
  - `<footer>`から`</body></html>`部分までを `footer.php` に切り出し。
  - 各ページの上下で `get_header();` と `get_footer();` を呼び出して共通化。
  - **重要ポイント**: `header.php`の`</head>`直前に `wp_head();`、`footer.php`の`</body>`直前に `wp_footer();` を必ず入れる（これがないとプラグインが動きません）。

### 3. トップページの実装
サイトの顔となるトップページを作りました。

- **作成したファイル**: `front-page.php`
- **やったこと**:
  - メインビジュアル、コンセプト紹介、各ページへの導線（セクション）をHTMLで構築。
  - `style.css`でデザインをあてる。レスポンシブ（スマホ表示）を考慮し、Flexbox (`display: flex;`) や Grid を活用して要素を配置。

### 4. 動的コンテンツの実装（お品書き）
メニュー情報を管理画面から簡単に追加・編集できるように、カスタム投稿タイプを活用しました。

- **作成・編集したファイル**: `archive-menu_item.php` （または `functions.php` での投稿タイプ定義）
- **やったこと**:
  - `functions.php` （もしくはプラグイン）で「お品書き（menu_item）」というカスタム投稿タイプを作成。
  - `archive-menu_item.php` を作成し、WordPressループ (`while (have_posts()) : the_post();`) を使って、登録されたメニュー画像やタイトル、価格を自動で一覧表示する仕組みを構築。

### 5. 静的ページの実装（アクセス・お問い合わせ）
固定ページとして、アクセス情報と問い合わせフォームを設置しました。

- **作成したファイル**: `page-access-contact.php`
- **やったこと**:
  - **Googleマップの埋め込み**: アクセス情報の箇所に、Googleマップのiframeタグを埋め込み表示。
  - **Contact Form 7 の連携**: お問い合わせフォームは「Contact Form 7」プラグインを使用。プラグイン側で生成されたショートコード（`[contact-form-7 id="..."]`）を、`do_shortcode()`関数を使ってPHPテンプレート内に埋め込み。
  - **フォームのスタイリング**: `style.css` にて、フォーム専用のスタイルを追加。他のページに影響が出ないよう、`.contact-form-wrapper` のような親要素のクラスを指定してCSSを記述しました（スコープの限定）。

### 6. 最終調整・リファクタリング（CSSの整理）
サイトが完成に近づいた段階で、コードの「お掃除」と「品質チェック」を行いました。

- **編集したファイル**: `style.css`
- **やったこと**:
  - **不要なコードの削除**: デザイン変更の過程で残ってしまった、効いていないCSSプロパティ（不要な`margin`や`position`など）を削除。
  - **セクションの整理**: CSSを「Reset / Typography / Layout / Components / Utilities / Media Queries」といった論理的なブロックに分け、コメントを挿入。どこに何が書いてあるか一目でわかるようにしました。
  - **レスポンシブの最終確認**: スマホサイズで見た時に、文字サイズや余白が適切か、横揺れ（意図せぬ横スクロール）が起きていないかを確認し、メディアクエリ（`@media`）で微調整。

## 💡 今後つまづいた時の「振り返りヒント」

1. **画面が真っ白になった / エラーが出た時**
   - → `functions.php` や他のPHPファイルで、セミコロン（`;`）が抜けていないか、カッコ（`{}`）が閉じられているかを確認。
2. **CSSが反映されない時**
   - → ブラウザのキャッシュ（履歴）が残っている可能性大。「スーパーリロード（Ctrl+F5）」を試すか、`functions.php`の`wp_enqueue_style`でファイルの更新バージョン（タイムスタンプなど）を付与する設定になっているか確認。
3. **プラグイン（フォームなど）のデザインが崩れる時**
   - → デベロッパーツール（F12）を開き、プラグインが強制的に適用しているCSS（`!important`など）がないか調査。自分のCSSが負けている場合は、親要素のクラスを足して「詳細度」を上げて上書きする。
4. **スマホで見ると横にはみ出す時**
   - → `width: 100vw;` が悪さをしているか、大きな画像がはみ出していることが多い。画像には `max-width: 100%; height: auto;` が当たっているか確認。
